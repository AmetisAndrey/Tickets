# Журнал дефектов и замечаний

Записи ниже выявлены при статическом просмотре архива. Это не означает, что приложение запускалось и дефекты воспроизведены. Статусы: **Открыт** — исправить; **Требует проверки** — подтвердить запуском; **Закрыт** — исправлен и проверен регрессионным тестом.

## D-01. overdue=false игнорируется
- **Статус:** Открыт · **Приоритет:** Средний
- **Файл:** `TicketService.list`
- **Наблюдение:** условие добавляется только при `Boolean.TRUE.equals(filter.overdue())`; false не фильтрует непросроченные заявки.
- **Шаги:** создать просроченную открытую заявку и вызвать `GET /api/tickets?overdue=false`.
- **Ожидание:** при семантике boolean-фильтра просроченная заявка исключается.
- **Фактическое:** условие overdue не добавляется.
- **Исправление:** реализовать обе ветки после согласования, должны ли закрытые заявки попадать в false.
- **Регрессия:** интеграционные тесты true и false на просроченной и непросроченной заявках.

## D-02. Kotlin-тест не вызывает реальную Java-реализацию
- **Статус:** Открыт · **Приоритет:** Средний (условие задания)
- **Файл:** `TicketReportDataPortTest.kt`
- **Наблюдение:** тест создаёт Mockito mock интерфейса `TicketReportDataPort`; класс `JpaTicketReportDataAdapter` не вызывается.
- **Ожидание:** хотя бы один Kotlin-тест проверяет Java-компонент.
- **Исправление:** Kotlin integration test со Spring/Testcontainers, реальным адаптером и проверкой выборки по датам.
- **Регрессия:** строка на from включается, строка на to исключается.

## D-03. CI/CD pipeline отсутствует в архиве
- **Статус:** Открыт · **Приоритет:** Высокий
- **Наблюдение:** конфигурация GitHub Actions/GitLab CI не обнаружена.
- **Ожидание:** анализ, сборка, тесты, публикация отчётов, сборка/публикация образа, развёртывание, health check; PR без deploy.
- **Исправление:** добавить pipeline, секреты и блокировку доставки при падении тестов.
- **Регрессия:** успешный pipeline и проверка, что упавший тест блокирует публикацию.

## D-04. Нет отчётов выполнения тестов и покрытия
- **Статус:** Требует проверки · **Приоритет:** Средний
- **Наблюдение:** тестовые исходники есть, отчётов выполнения/coverage в архиве нет.
- **Ожидание:** сохранены отчёты запуска и покрытия Java/Kotlin.
- **Исправление:** выполнить Gradle tests в среде с Docker, настроить JaCoCo или аналог.
- **Регрессия:** pipeline формирует и публикует отчёты.

## D-05. Не описаны backup/restore
- **Статус:** Открыт · **Приоритет:** Средний
- **Наблюдение:** настроен named volume, но не найдены команды резервного копирования/восстановления и подтверждение восстановления в отдельную БД.
- **Ожидание:** backup/restore инструкция и проверка сохранности данных.
- **Исправление:** добавить pg_dump/pg_restore или psql процедуры и выполнить тест.
- **Регрессия:** создать заявку, сделать backup, восстановить в тестовую БД, проверить запись.

## D-06. Не подтверждён чистый запуск
- **Статус:** Требует проверки · **Приоритет:** Высокий
- **Наблюдение:** Compose есть, но нет протокола запуска, health check и перезапуска с сохранением данных.
- **Исправление:** после D-01/D-02 проверить чистый запуск и описать диагностику.
- **Регрессия:** `docker compose down`, затем `docker compose up --build`; данные сохраняются (не использовать `down -v`).
