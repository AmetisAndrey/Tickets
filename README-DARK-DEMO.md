# Tixdesk — dark theme + demo data

## Что изменено
- Интерфейс переведён на тёмную цветовую схему.
- Добавлена Flyway-миграция `V2__seed_demo_data.sql` с 18 демонстрационными заявками и историей статусов.
- Сохранены существующие API, Java/Kotlin-код и логика приложения.

## Запуск
```powershell
docker compose up --build
```
После запуска откройте http://localhost:8080.

## Данные
Демо-данные добавляются миграцией автоматически при первом старте приложения.
Если база уже существует, Flyway применит только новую миграцию V2.
Чтобы заново создать чистую демонстрационную базу (ВНИМАНИЕ: удалит данные в Docker volume):
```powershell
docker compose down -v
docker compose up --build
```
Не выполняйте `down -v`, если в базе есть нужные данные.
